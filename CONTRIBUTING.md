# Contributing

Thanks for helping improve the watch comparison.

1. Open a pull request against `main` with a short explanation of the change.
2. For a new or corrected measurement, include a link to the manufacturer's published specification or dimensional drawing. Note whether thickness includes the rear sensor.
3. For a case, button or side-profile change, include an official product image or drawing that shows the relevant feature. Keep the illustration clearly identified as approximate where exact dimensions are unavailable.
4. Check the page at a narrow and wide window size and make sure existing watch toggles still work.

The repository owner reviews changes before they are merged. A preview deployment is created for each pull request so changes can be checked on the web.
